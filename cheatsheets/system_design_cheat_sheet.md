# System Design Numbers Everyone Should Know
- L1 cache reference: 0.5 ns
- Main memory reference (RAM): 100 ns
- Read 1 MB sequentially from memory: 3,000 ns (3 µs)
- Read 1 MB sequentially from NVMe SSD: 200,000 ns (200 µs)
- Round trip within same datacenter: 500,000 ns (0.5 ms)
- Read 1 MB sequentially from spinning disk: 10,000,000 ns (10 ms)
- Send packet CA to Netherlands and back: 150,000,000 ns (150 ms)
