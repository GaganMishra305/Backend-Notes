# OpenTelemetry (OTel) 3 Pillars
1. **Traces**: Request journey across distributed microservices (Trace ID, Span ID, Parent Span ID, Attributes).
2. **Metrics**: Numerical measurements aggregated over time (Counters, UpDownCounters, Histograms).
3. **Logs**: Structured event records correlated with active Trace ID and Span ID for instant log filtering in Jaeger/Grafana Loki.
