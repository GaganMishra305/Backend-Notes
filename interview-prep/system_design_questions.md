# Top System Design Questions Checklist
1. Design a URL Shortener (TinyURL) - Base62 encoding, KGS, cache layer.
2. Design a Rate Limiter - Token bucket, Redis sliding window counter.
3. Design a Key-Value Store - Consistent hashing, replication, vector clocks.
4. Design a Distributed Message Queue - Commit log, partitioned consumer groups.
5. Design Web Crawler - URL frontier, deduplication, robots.txt caching.
